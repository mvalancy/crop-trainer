Crop Trainer uses neural voices for spoken audio. All inference and pronunciation processing run locally. The separately licensed assets below are distributed with their original notices.

English: Kokoro v1.0, af_heart. Apache 2.0. The Q8 ONNX export is split in order into model-1.bin through model-4.bin. heart.bin is the named speaker embedding.
https://huggingface.co/hexgrad/Kokoro-82M
https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0
https://www.npmjs.com/package/kokoro-js/v/1.2.1
See apache.txt.

Arabic: ar_JO-kareem-medium. Spanish: es_ES-davefx-medium. Mandarin Chinese: zh_CN-huayan-medium. French: fr_FR-siwis-medium. Models are unmodified Piper ONNX files split into consecutive pieces. The Piper Voices repository is MIT licensed. The original per-voice model cards, including the upstream training dataset notes, are supplied as ar-voice.txt, es-voice.txt, zh-voice.txt and fr-voice.txt.
https://huggingface.co/rhasspy/piper-voices
https://huggingface.co/rhasspy/piper-voices/blob/main/README.md

Arabic vowel restoration: libtashkeel, distributed with piper-tts 1.8.0. Input and output alphabets come from the same distribution. Upstream source and model:
https://github.com/mush42/libtashkeel
https://github.com/OHF-Voice/piper1-gpl/tree/main/src/piper/tashkeel

ONNX Runtime Web 1.22.0, Microsoft. MIT. See onnx-license.txt and onnx-notices.txt. The runtime, binding and SIMD Wasm module are the CPU-only artifacts in the published npm distribution.
https://www.npmjs.com/package/onnxruntime-web/v/1.22.0
https://github.com/microsoft/onnxruntime

English phoneme conversion: phonemizer 1.2.1, Apache 2.0 wrapper, includes eSpeak NG (GPL v3 or later).
https://github.com/xenova/phonemizer.js
Other languages: @echogarden/espeak-ng-emscripten 0.3.5, GPL v3. The pronunciation data is packaged with cli/voice/package-dictionaries.py. The source of the wrapper, native engine and build instructions are at:
https://github.com/echogarden-project/espeak-ng-emscripten
https://github.com/echogarden-project/espeak-ng/tree/fork
See espeak-license.txt. No eSpeak waveform is played.

App narration maintenance, from the repository root:
  node cli/languages/review.mjs ar
  node cli/voice/plan.mjs ar > /tmp/crop-ar-jobs.json
  python cli/voice/record.py ar /tmp/crop-ar-jobs.json ar_JO-kareem-medium.onnx ar_JO-kareem-medium.onnx.json

For English use kokoro-v1.0.int8.onnx and voices-v1.0.bin. A recording's source text is the visible transcript. Section recordings use stable content hashes. The reader synthesizes new material until a recording is added. To update previously recorded activity introductions, regenerate their named files with --replace.
