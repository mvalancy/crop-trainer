About the files

PLY contains little-endian XYZ coordinates in metres. The label file gives each plant’s bounding box and crop return count. The recipe and scan link use the settings of the displayed scan. Choose Grow and scan to apply your edits.

How the scanner samples a crop

Grid profiles distribute jittered samples over the plot. Line and sweep profiles change coverage along and across rows. Ring layouts use angular columns and channels, capped by the ray budget. The synthetic renderer takes the highest surface at each sample. Hardware-inspired presets reproduce selected channel and column counts. Beam calibration, pulse intensity, motion and multiple returns would require a richer sensor model. Ouster sensor data reference

Where would you put a pin?

Look down on your lettuce scan. Brighter dots are higher. Place a pin where you see a plant, then compare it with the planting map.

What changes during training?

A model gives each possible plant center a score. A weight controls how strongly a clue, such as height, affects that score.

Try teaching this tiny model from one labeled plant. Then take the full detector to the Training Shed, where it learns from many examples and tests its pins on fresh fields.
